The core intuition of feedback

Intuition 1 · The Fundamental Trade-Off

In open-loop amplifiers, voltage gain depends heavily on transistor parameters like hfe and gm, which vary wildly (up to 300%) with temperature and batch manufacturing. Negative feedback introduces a fraction β of the output back to oppose the input signal. We sacrifice raw open-loop gain A to gain rock-solid stability, wider bandwidth, and reduced distortion. When loop gain Aβ >> 1, closed-loop gain becomes Af ≈ 1/β, determined entirely by passive resistors!

Intuition 2 · The Desensitivity Factor (1 + Aβ)

Every major benefit of negative feedback is scaled by the amount of feedback (1 + Aβ) (also called the return difference or desensitivity factor D):

  • Gain decreases by (1 + Aβ): Af = A / (1 + Aβ)
  • Gain instability decreases by (1 + Aβ): (dAf/Af) = (1 / (1 + Aβ)) · (dA/A)
  • Bandwidth multiplies by (1 + Aβ): BWf = BW · (1 + Aβ)
  • Harmonic distortion divides by (1 + Aβ): Df = D / (1 + Aβ)
Intuition 3 · The Golden Rule of Impedances

Memorize this foolproof two-part rule for input and output impedance under feedback:

  • Input Mixing: Series connection at input always increases input impedance by (1 + Aβ): Zif = Zi(1 + Aβ). Shunt (parallel) connection at input always decreases input impedance: Zif = Zi / (1 + Aβ).
  • Output Sampling: Voltage sampling (parallel connection across output) always decreases output impedance: Zof = Zo / (1 + Aβ). Current sampling (series connection in output branch) always increases output impedance: Zof = Zo(1 + Aβ).

Topic 2

Feedback concept & transfer gain derivation

Loop Transfer FunctionBarkhausen & Stability
Intuition

Feedback is the process of taking a sample of the output signal and feeding it back into the input. If the returned signal adds to the input, it is positive feedback (amplification grows until oscillation or saturation). If it subtracts from the input, it is negative feedback (self-correcting control loop).

2.1 Mathematical Derivation of Closed-Loop Gain Af

Let:

  • Xs = externally applied input signal (voltage or current)
  • Xf = feedback signal returned by the feedback network
  • Xi = effective input signal applied to the basic amplifier
  • Xo = output signal
  • A = open-loop gain = Xo / Xi
  • β = feedback factor (transfer ratio) = Xf / Xo

At the input comparator (mixer), for negative feedback:

X_{i} = X_{s} − X_{f} = X_{s} − β X_{o}

The basic amplifier amplifies Xi:

X_{o} = A X_{i} = A (X_{s} − β X_{o}) = A X_{s} − A β X_{o}

Rearranging terms to collect Xo on the left side:

X_{o} (1 + A β) = A X_{s}

Dividing by Xs gives the celebrated transfer gain with feedback formula:

A_{f} = [[X_{o}|X_{s}]] = [[A|1 + A β]]

Key quantities:

  • Loop Gain (Return Ratio): T = Aβ
  • Amount of Feedback (Desensitivity Factor): D = 1 + Aβ
  • High Loop Gain Limit: When |Aβ| >> 1, Af ≈ [[A|A β]] = [[1|β]]. The closed-loop gain is completely independent of transistor parameters!

Topic 4

Effect on gain stability and bandwidth

Winter 2025 Q4 OR (10 Marks)DesensitizationGain-Bandwidth Product
Intuition

Why do we accept a drop in gain? Because it gives us gain desensitization. If the transistor's internal gain drifts by 20% due to heat or ageing, negative feedback can reduce that variation to less than 0.2%!

4.1 Derivation of Gain Desensitization (Sensitivity)

Starting from the closed-loop gain equation:

A_{f} = [[A|1 + A β]]

Differentiating Af with respect to the open-loop gain A:

[[dA_{f}|dA]] = [[(1 + A β)(1) − A (β)|(1 + A β)^{2}]] = [[1 + A β − A β|(1 + A β)^{2}]] = [[1|(1 + A β)^{2}]]

Divide both sides by Af = A / (1 + Aβ):

[[dA_{f}|A_{f}]] = [[1|1 + A β]] · [[dA|A]]

Conclusion: The fractional percentage change in closed-loop gain ([[dA_{f}|A_{f}]]) is equal to the fractional change in open-loop gain ([[dA|A]]) divided by the desensitivity factor (1 + Aβ)!

4.2 Effect on Bandwidth and Cutoff Frequencies

Consider an amplifier with lower cutoff frequency f1 and upper cutoff frequency f2. Negative feedback affects both ends of the frequency spectrum:

  • Upper Cutoff Frequency (f2): Feedback extends high-frequency response because negative feedback diminishes at high frequencies, flattening the gain curve:
    f_{2f} = f_{2} (1 + A_{mid} β)
  • Lower Cutoff Frequency (f1): Low-frequency roll-off occurs lower down the spectrum:
    f_{1f} = [[f_{1}|1 + A_{mid} β]]
  • Overall Bandwidth (BW):
    BW_{f} = f_{2f} − f_{1f} ≈ f_{2} (1 + A_{mid} β) = BW · (1 + A_{mid} β)
  • Gain-Bandwidth Product (GBW):
    A_{f(mid)} · BW_{f} = [[A_{mid}|1 + A_{mid} β]] · [BW (1 + A_{mid} β)] = A_{mid} · BW = Constant
    The gain-bandwidth product is strictly invariant under feedback. Gain is traded directly for bandwidth!

Topic 5

Effect on non-linear distortion and noise

Harmonic Distortion DfSignal-to-Noise Ratio
Intuition

When an amplifier operates with large signals, non-linear curvature in transistor characteristics introduces unwanted harmonics (2nd, 3rd harmonics). Negative feedback senses the distortion generated inside the amplifier and subtracts an anti-phase replica at the input, cancelling out the harmonic content!

5.1 Reduction of Non-Linear Distortion

Let D be the harmonic distortion voltage generated within the open-loop amplifier. With negative feedback applied, the distorted component circulating through the loop is returned as β Df and subtracted at the input.

D_{f} = D − A β D_{f} ⇒ D_{f} (1 + A β) = D
D_{f} = [[D|1 + A β]]

Important Caveat: This distortion reduction holds when the closed-loop output signal amplitude is restored to the open-loop level by boosting input excitation, assuming the preceding pre-amplifier stage generates zero distortion.

5.2 Effect of Negative Feedback on Noise

Let noise voltage Vn be generated in an intermediate stage of the amplifier (e.g. power-supply hum, thermal noise). Negative feedback reduces noise generated inside the loop by the factor (1 + Aβ):

V_{nf} = [[V_{n}|1 + A β]]

However, noise entering at the input terminal (such as sensor thermal noise) is amplified by exactly the same closed-loop gain as the signal. Therefore, negative feedback does NOT improve the Signal-to-Noise Ratio (SNR) for input noise. It only suppresses noise generated in subsequent stages within the loop!

Topic 6

Effect on input and output impedance

Winter 2025 Q4 (10 Marks)Summer 2026 Q4 OR (10 Marks)Impedance Derivations
Intuition

Remember the simple rule:

  • Series mixing at input: Opposing feedback voltage Vf opposes Vs, so input current Ii drops dramatically $⇒$ Input impedance increases: Zif = Zi (1 + Aβ).
  • Shunt mixing at input: Feedback current If draws away current in parallel, so from the source's view it takes more total current $⇒$ Input impedance decreases: Zif = Zi / (1 + Aβ).
  • Voltage sampling at output: If output voltage Vo tries to rise, feedback sends a large opposing signal to pull it down (like a stiff voltage regulator) $⇒$ Output impedance decreases: Zof = Zo / (1 + Aβ).
  • Current sampling at output: If output current Io tries to change, feedback opposes the change (like an ideal constant current source) $⇒$ Output impedance increases: Zof = Zo (1 + Aβ).

6.1 Voltage-Series Derivation (Winter 2025 Q4)

Input Impedance (Zif):

V_{s} = V_{i} + V_{f} = I_{i} Z_{i} + β V_{o} = I_{i} Z_{i} + β (A V_{i}) = I_{i} Z_{i} + A β (I_{i} Z_{i}) = I_{i} Z_{i} (1 + A β)
Z_{if} = [[V_{s}|I_{i}]] = Z_{i} (1 + A β)

Output Impedance (Zof): To find Zof, set signal source Vs = 0 and apply an external test voltage V at the output port:

V_{s} = 0 ⇒ V_{i} = −V_{f} = −β V

The current I delivered by test source into the output port:

I = [[V − A V_{i}|Z_{o}]] = [[V − A(−β V)|Z_{o}]] = [[V (1 + A β)|Z_{o}]]
Z_{of} = [[V|I]] = [[Z_{o}|1 + A β]]

6.2 Current-Shunt Derivation (Summer 2026 Q4 OR)

Input Impedance (Zif): Shunt mixing connects feedback current in parallel with input:

I_{s} = I_{i} + I_{f} = I_{i} + β I_{o} = I_{i} + β (A_{i} I_{i}) = I_{i} (1 + A_{i} β)

Since input voltage is Vi = Ii Zi:

Z_{if} = [[V_{i}|I_{s}]] = [[I_{i} Z_{i}|I_{i} (1 + A_{i} β)]] = [[Z_{i}|1 + A_{i} β]]

Output Impedance (Zof): Current sampling increases output impedance:

Z_{of} = Z_{o} (1 + A_{i} β)

Topic 7

BJT voltage-series feedback amplifier

Two-Stage RC-Coupled CEExact Notes Worked Example
Intuition

To implement voltage-series feedback with BJTs, why do we use a two-stage amplifier? Because each CE stage introduces a 180° phase inversion. Two cascaded CE stages produce 180° + 180° = 360° (0°) overall phase shift. When the output voltage at the second collector is fed back to the emitter of the first stage, the emitter voltage rises in phase with the base signal, which subtracts from Vbe1 (Vbe1 = Vb1 − Ve1), creating true negative feedback!

7.1 Circuit Analysis & Formulas

The feedback factor β is set by the resistive divider from Q2 collector to Q1 emitter:

β = [[R_{f2}|R_{f1} + R_{f2}]]

The closed-loop voltage gain for large loop gain:

A_{vf} = [[A_{v}|1 + A_{v} β]] ≈ [[1|β]] = [[R_{f1} + R_{f2}|R_{f2}]] = 1 + [[R_{f1}|R_{f2}]]

7.2 Solved Problem: Exact Numerical Example from Dr. Ghongade's Notes

Worked Example 1 (From Handwritten Teaching Notes)

Given Data: A two-stage RC-coupled CE BJT amplifier has open-loop voltage gain Av = 1118, input resistance Zi = 1.98 kΩ, and output resistance Zo = 12 kΩ. The feedback network uses Rf1 = 16.2 kΩ and Rf2 = 220 Ω.

  1. Calculate feedback factor β:
    β = [[R_{f2}|R_{f1} + R_{f2}]] = [[220|16200 + 220]] = [[220|16420]] = 0.0134
  2. Calculate loop gain and desensitivity factor:
    A_{v} β = 1118 × 0.0134 = 14.98 ⇒ 1 + A_{v} β = 1 + 14.98 = 15.98
  3. Calculate closed-loop voltage gain Avf:
    A_{vf} = [[A_{v}|1 + A_{v} β]] = [[1118|15.98]] = 69.96 ≈ 70
    Check with approximation: 1/β = 16420 / 220 = 74.6.
  4. Calculate closed-loop input impedance:
    Z_{if} = Z_{i} (1 + A_{v} β) = 1.98 kΩ × 15.98 = 31.64 kΩ
  5. Calculate closed-loop output impedance:
    Z_{of} = [[Z_{o}|1 + A_{v} β]] = [[12 kΩ|15.98]] = 750.9 Ω

7.3 Complete Design Procedure (Capacitor Selection at fL = 100 Hz)

From the notes, for fL = 100 Hz:

  • Bypass capacitor C2 at Rf2:
    |X_{C2}| = R_{f2} ⇒ C_{2} = [[1|2 π f_{L} R_{f2}]] = [[1|2 π (100) (220)]] = 7.23 µF ⇒ Select Standard 8 µF or 10 µF
  • Decoupling capacitor Cf1:
    C_{f1} = [[1|2 π f_{L} (R_{f1}/100)]] = [[1|2 π (100) (162)]] = 9.8 µF ⇒ Select Standard 10 µF
Topic 8

BJT current-series feedback amplifier

CE with Unbypassed RE1Gain Stabilization6-Step Design
Intuition

The simplest and most widely used negative feedback circuit in electronics is a single CE transistor stage where the emitter resistor is split into two parts: an unbypassed resistor RE1 and a bypassed resistor RE2. The emitter current IE flows through RE1, developing a feedback voltage Vf = IE RE1 directly in series with the input!

8.1 Analytical Derivations

1. Transistor Base Input Impedance (Zb):

Z_{b} = h_{ie} + (1 + h_{fe}) R_{E1}

Total amplifier input impedance:

Z_{in} = R_{1} || R_{2} || Z_{b}

2. Small-Signal Voltage Gain:

A_{v} = − [[h_{fe} (R_{C} || R_{L})|h_{ie} + (1 + h_{fe}) R_{E1}]]

When (1 + hfe)RE1 >> hie and since hfe/(1+hfe) ≈ 1:

A_{v} ≈ − [[R_{C} || R_{L}|R_{E1}]]

Notice that the voltage gain depends only on passive circuit resistors and is virtually independent of hfe!

8.2 Solved Example: Exact hfe Variation from Dr. Ghongade's Notes

Worked Example 2 (From Notes)

Circuit values: RC = 12 kΩ, RL = 120 kΩ (giving RC∥RL = 10.91 kΩ), RE1 = 150 Ω.
Test the gain stability across extreme transistor production spreads:

  • At maximum parameters: hfe = 400, hie = 5 kΩ:
    |A_{v(max)}| = [[400 (10.91 kΩ)|5 kΩ + (1 + 400)(150 Ω)]] = [[4364|5 + 60.15]] = 67.0
  • At minimum parameters: hfe = 100, hie = 2 kΩ:
    |A_{v(min)}| = [[100 (10.91 kΩ)|2 kΩ + (1 + 100)(150 Ω)]] = [[1091|2 + 15.15]] = 63.6

Result: While hfe varied by 300% (from 100 to 400), the voltage gain changed by only 5.3% (from 63.6 to 67.0)! This proves the immense gain-stabilizing power of emitter-current feedback.

    R_{E1} ≈ [[R_{C} || R_{L}|A_{v}]] = [[10.91 kΩ|70]] = 155.8 Ω ⇒ Select Standard 150 Ω

    R_{E2} = R_{E(orig)} − R_{E1} = 3.9 kΩ − 150 Ω = 3.75 kΩ ⇒ Select Standard 3.9 kΩ

    Z_{b} = h_{ie} + (1 + h_{fe}) R_{E1} = 2 kΩ + (101)(150 Ω) = 17.15 kΩ

    Z_{in} = 120 kΩ || 39 kΩ || 17.15 kΩ ≈ 10.8 kΩ
  5. Calculate input coupling capacitor C1:
    |X_{C1}| = [[Z_{in} + R_{s}|10]] ⇒ C_{1} = [[1|2 π (100) (1140)]] = 1.39 µF ⇒ Select Standard 1.5 µF
  6. Calculate emitter bypass capacitor C2:
    |X_{C2}| = R_{E1} ⇒ C_{2} = [[1|2 π (100) (150)]] = 10.61 µF ⇒ Select Standard 12 µF
Topic 9

BJT current-shunt feedback amplifier

DC Feedback PairCurrent Gain StabilizationDesign Example
Intuition

The current-shunt feedback configuration uses a two-transistor DC feedback pair. The output current Io in the emitter of Q2 is sampled through resistor Rf2, and feedback current If is returned in parallel (shunt) to the base of Q1 through Rf1. This configuration lowers input impedance to tens of ohms, making it an outstanding current amplifier!

9.1 Circuit Operation & Derivations

At the input node, source current splits: is = ii + if. At the feedback sampling point, output current splits between Rf1 and Rf2:

β = [[R_{f2}|R_{f1} + R_{f2}]]

Closed-loop current gain:

A_{if} = [[I_{o}|I_{s}]] = [[A_{i}|1 + A_{i} β]] ≈ [[1|β]] = [[R_{f1} + R_{f2}|R_{f2}]]

Input impedance with feedback:

Z_{if} = [[h_{ie1}|1 + A_{i} β]]

9.2 Solved Design Example from Dr. Ghongade's Notes

Worked Example 3 (From Notes)

Specification: Design a current-shunt feedback amplifier to achieve closed-loop current gain Aif = 55 using the designed DC pair (VCC = 12 V, IC = 2 mA, hfe = 100, hie = 2 kΩ, Ai(open) = 6226).

  1. Obtain feedback resistor ratio:
    A_{if} ≈ [[R_{f1} + R_{f2}|R_{f2}]] = 55 ⇒ [[R_{f1}|R_{f2}]] = 54 ⇒ R_{f1} = 54 R_{f2}
  2. Select standard Rf2 and compute Rf1:

    As per the notes, choose Rf2 between 100 Ω and 470 Ω. Let Rf2 = 100 Ω:

    R_{f1} = 54 × 100 Ω = 5.4 kΩ ⇒ Select Standard 5.6 kΩ
  3. Split original bias resistor R2 = 180 kΩ:
    R_{5} = R_{2} − R_{f1} = 180 kΩ − 5.6 kΩ = 174.4 kΩ ⇒ Select Standard 180 kΩ
  4. Calculate feedback coupling capacitor Cf1 at fL = 150 Hz:
    |X_{Cf1}| = [[R_{f1}|100]] ⇒ Selected in notes: C_{f1} = 2.2 µF

Topic 10

BJT voltage-shunt feedback amplifier

Collector-to-Base FeedbackTransresistance Stabilization
Intuition

In a voltage-shunt feedback amplifier, a feedback resistor Rf is connected directly from the collector (output voltage) back to the base (input current) of a CE stage. Output voltage is sampled, and feedback is returned in shunt. Both input and output impedances are drastically reduced, and the circuit acts as a highly stable transresistance amplifier!

10.1 Circuit Analysis & Formulas

Feedback current returning to base:

I_{f} = [[V_{i} − V_{o}|R_{f}]] ≈ − [[V_{o}|R_{f}]] = β V_{o} ⇒ β = − [[1|R_{f}]]

The open-loop transresistance Rm without feedback is defined as Vo / Is:

R = R_{s} || R_{f1}, R_{C}' = R_{C} || R_{f2}
R_{m} = − [[h_{fe} R_{C}' R|R + h_{ie}]]

The closed-loop transresistance:

R_{mf} = [[R_{m}|1 + β R_{m}]] = − [[h_{fe} R_{C}' R R_{f}|R_{f}(R + h_{ie}) + h_{fe} R_{C}' R]]

When loop gain is very large, Rmf simplifies to:

R_{mf} ≈ [[1|β]] = − R_{f}

The overall voltage gain is simply:

A_{vf} = [[V_{o}|V_{s}]] = [[R_{mf}|R_{s}]] ≈ − [[R_{f}|R_{s}]]
Topic 11

Consolidated summary & topology identification rule

3-Step Identification AlgorithmMaster Comparison
Intuition

Exam questions often ask you to classify an unfamiliar circuit. Follow this infallible 3-step decision procedure:

  1. Determine Output Sampling: Look at the output node.
    • If feedback network is connected directly in parallel with the output terminals (so setting Vo = 0 removes the feedback signal), it is Voltage Sampling.
    • If feedback network is in series with the load (so opening the load loop reduces feedback signal to zero), it is Current Sampling.
  2. Determine Input Mixing: Look at the input node.
    • If feedback signal is in series with the external source (loops around base-emitter loop: Vi = Vs − Vf), it is Series Mixing.
    • If feedback signal connects directly to the same node as the input source (KCL: Ii = Is − If), it is Shunt Mixing.
  3. Apply the Impedance Rule:
    • Series mixing $⇒$ Zin multiplies by (1 + Aβ).
    • Shunt mixing $⇒$ Zin divides by (1 + Aβ).
    • Voltage sampling $⇒$ Zout divides by (1 + Aβ).
    • Current sampling $⇒$ Zout multiplies by (1 + Aβ).
